# rlin client

> 一个面向 Android 的 Minecraft 客户端风格界面模块：游戏内的 **ClickGUI + 一组 HUD + 实时背景模糊 / 液态玻璃**，
> 以 Xposed（旧版 API 82）模块的形式运行，可以通过 LSPosed，或用 LSPatch / OPatch 之类的补丁框架打进游戏里。
> 同一个 App 还能在手机桌面上直接打开，当作界面预览 / 调样式的 Demo。

**请先读：** 本项目只负责**界面与渲染层**（面板、HUD、模糊、动画、音乐播放器）。
模块列表里的功能卡片默认只是界面，**没有接入任何真实的游戏逻辑**（后端是预留的接口）。
HUD 显示的数据（方块数、周围目标、药水效果等）需要由你自己的逻辑通过下文的「数据接口」推送，没有数据时 HUD 会显示演示数据。
在多人游戏里使用任何修改客户端都可能导致封号，**风险自负**，作者不对由此产生的任何后果负责。

## 它能做什么

- **ClickGUI**：左侧分类栏（战斗 / 移动 / 渲染 / 玩家 / 其他），右侧 2 列模块卡片，点开设置卡片调滑条、开关、分段选项和取色。
- **11 种 HUD**：水印、模块列表、目标信息、药水效果、帧率、速度计、坐标、方块计数、雷达、灵动岛、开关提示。每个都能单独开关、拖动、缩放、调透明度、调辉光和边缘阴影。
- **实时背景模糊**：在游戏画面上直接做双重 Kawase 模糊，GUI 和 HUD 背后都是真正透出游戏画面的毛玻璃。
- **液态玻璃（实验）**：可选的另一种玻璃风格——边缘折射、色散和高光。
- **外观**：深色 / 浅色、预设主题色、PS 风格取色器自定义强调色（其余配色自动跟着变），简体中文 / English。
- **音乐播放器**：独立的音乐页，支持在线搜索播放和歌词。
- **桌面 App**：不进游戏也能完整预览界面。

## 运行要求

| 项目 | 要求 |
|---|---|
| 系统 | Android 9（API 28）及以上 |
| 架构 | arm64-v8a |
| 游戏渲染后端 | **OpenGL ES 3.0 及以上**。游戏走 Vulkan 时，实时模糊钩不到（界面仍可显示，但没有毛玻璃） |
| 框架 | 支持旧版 Xposed API（82）的框架：LSPosed，或 LSPatch / OPatch 之类的补丁框架 |
| 目标游戏 | 作用域里预置了 `com.netease.x19` 和 `com.mojang.minecraftpe`，其它包名请在框架里手动勾选 |
| 液态玻璃（桌面 Demo 预览） | Android 13（API 33）及以上；游戏内是原生着色器，不受这个限制 |

## 安装

1. 从 Releases 下载 APK 并安装。
2. 选一种方式让它进入游戏：
   - **LSPosed**：在 LSPosed 管理器里启用本模块，作用域勾选目标游戏，然后强制停止并重新打开游戏。
   - **LSPatch / OPatch 类**：用你的补丁框架把本模块嵌入目标游戏的 APK（或以本地模块方式加载），重新安装补丁后的游戏。具体步骤以你使用的框架说明为准。
3. 打开游戏，屏幕上会出现一个**悬浮球**，说明模块已经加载。

> 如果没有悬浮球：先确认框架里模块已启用且作用域正确；再看 `logcat` 里 tag 为 `rlin` 的日志（会写明原生库是否加载成功、模糊钩子是否挂上）。

## 第一次使用

点悬浮球打开 ClickGUI，首次会出现一个小的引导卡片（欢迎 → 登录 → 语言 → 进入）。
完成后就是正常的主界面。悬浮球可以任意拖动，位置会被记住。

## 界面怎么用

- **打开 / 关闭**：点悬浮球；点面板外的空白处、或按返回键也能关闭。
- **开关模块**：点卡片右侧的开关。点卡片最右边的小箭头，弹出该模块的设置卡片。
- **悬浮快捷键**：在模块设置卡片里打开「悬浮快捷键」，屏幕上就会多一个该模块的小开关，可拖动，点一下切换模块。
- **搜索**：顶部搜索框可按名称或说明搜索当前分类下的模块。
- **左下角的用户卡片**：进入账号页，管理软件账号和游戏账号。
- **HUD 区**（左栏下方）：
  - 「添加 HUD」：勾选要显示的 HUD；
  - 「编辑 HUD」：进入编辑模式，直接在屏幕上拖动、对齐 HUD，选中后在底部设置它的选项；
  - 「音乐」：打开音乐页。

## HUD 一览

在「添加 HUD」里打开想要的 HUD，之后每个 HUD 都可以在编辑模式里调整位置、大小、不透明度、背景模糊开关，以及它自己的选项。

| HUD | 说明 | 数据来源 |
|---|---|---|
| 水印 | 客户端名称、账号与状态，多种样式 | 内置 |
| 模块列表 | 已启用模块的列表，支持渐变配色 | 内置（读取模块开关状态） |
| 目标信息 | 战斗对象的名字与生命 | 需推送（有演示数据） |
| 药水效果 | 环形倒计时 / 条形两种样式，最后 10 秒变红 | 需推送（有演示数据） |
| 帧率 | 帧率数字 + 最近一段时间的柱状图 | 内置 |
| 速度计 | 移动速度（格/秒或千米/时）+ 柱状图 | 需推送（有演示数据） |
| 坐标 | XYZ、朝向、下界 ÷8 换算 | 需推送（有演示数据） |
| 方块计数 | 搭路时的方块数量、进度条与速度，少于 32 变红 | 需推送（有演示数据） |
| 雷达 | 圆角方块雷达，最近的敌人高亮 | 需推送（有演示数据） |
| 灵动岛 | 常驻名称与状态，模块开关时展开提示，另有「终末地」「材质」样式 | 内置 |
| 开关提示 | 模块开关时从右下角弹出的提示卡片，5 种样式 | 内置 |

没有真实数据时，HUD 默认显示**演示数据**（每个 HUD 的选项里都有「演示数据」开关）。

## 外观、模糊与液态玻璃

在分类「其他」里找到 **ClickGUI 管理**，点右侧箭头打开设置：

| 设置 | 说明 |
|---|---|
| 界面模糊 | 总开关。关闭后 GUI 和 HUD 都变成纯色扁平 |
| 模糊风格 | **毛玻璃**（默认）/ **液态玻璃**（实验） |
| 液态玻璃强度 | 控制折射带宽度、色散和高光 |
| 界面缩放 | 75% – 125% |
| 界面透明度 | 60% – 100% |
| 外观模式 | 深色 / 浅色 |
| HUD 配色 | 「保持深色」或「跟随外观」 |
| 主题色 | 预设 3 种 + 「自定义」 |
| 自定义调色板 | 类似 PS 的取色器（饱和度×明度方块 + 色相条）；选好强调色后，底色、文字色、卡片色会按它自动配色 |
| 语言 | 简体中文 / English |

改完外观设置后，界面会在原地刷新，并回到你当前所在的分类。

**关于液态玻璃：** 它把玻璃当成一块凸透镜，只在边缘一圈折射背后的内容，同时带轻微色散、磨砂和沿边缘的高光。
这是实验功能：不同机型 GPU 的表现可能不同，如果觉得看不清字或有性能问题，随时切回「毛玻璃」。

## 音乐播放器

点左栏的「音乐」进入。支持在线搜索、播放队列、歌词（LRCLIB），并可在灵动岛里显示播放状态。

在音乐页的设置里可以选择音源：Jamendo、Internet Archive、自定义 API、网易云风格 API（需要你自己填服务地址，可选 Cookie），以及 GD 音乐台（可选平台与音质）。
- 第三方音源的可用性、合法性由使用者自行负责；
- 本项目**不提供**任何破解 VIP / DRM 的功能。

## 桌面 Demo

安装后桌面上会有一个图标。点开就是和游戏里一样的体验：悬浮球、ClickGUI、所有 HUD（演示数据）、HUD 编辑模式都能用，只是背后没有游戏画面。

- 毛玻璃用一张**预先模糊好的背景图**代替实时模糊，所以很流畅；
- 右下角的圆形按钮可以**更换背景图片**（从相册选），**长按**恢复默认的渐变光斑背景；
- Demo 和游戏里是**两套独立的设置**，在 Demo 里调样式不会同步进游戏。

## 彩蛋

在 ClickGUI 左栏**长按「音乐」**。会自动关闭 GUI，并放出一个带声音的小视频：它像早期 DVD 待机画面一样在整个屏幕上来回弹，
所有属于本客户端的控件（各个 HUD、悬浮球、悬浮快捷键、GUI 面板和视频本身）会跟着鼓点上下 Q 弹地挤压弹跳。
**长按视频**即可结束，一切恢复原样。

> 视频文件放在 `app/src/main/assets/bangyou.mp4`，鼓点时间表在 `bangyou_beats.txt`。想换成自己的视频，直接替换这两个文件即可
>（鼓点表是用空格分隔的秒数，可以不提供，那样会按固定节奏弹）。
> **注：视频因版权原因不随源码仓库分发**，自行把视频放入 `app/src/main/assets/bangyou.mp4` 即可（`bangyou_beats.txt` 在仓库里）。

## 常见问题

**打开游戏没有悬浮球？**
确认模块已启用、作用域包含目标游戏，并且是在重启游戏后查看。查看 `logcat` 中 tag 为 `rlin` 的日志。

**有界面但没有模糊？**
先看「ClickGUI 管理 → 界面模糊」是否开着。其次游戏必须是 OpenGL ES 3.0+ 渲染；走 Vulkan 的版本钩不到。

**模块开了但游戏里没有任何变化？**
正常。模块卡片默认只是界面，没有接入游戏逻辑，见页首说明。

**HUD 显示的是假数据？**
没有收到真实数据时会显示演示数据。你可以在每个 HUD 的选项里关闭「演示数据」，并按下文接入真实数据。

**打开 GUI 或切换分类有点卡？**
可以试试：关闭「界面模糊」或切到「毛玻璃」风格；调低界面缩放；把界面透明度保持在 100%（低于 100% 时整个面板需要额外的离屏合成）。

**长按音乐没反应？**
需要先有可用的悬浮球 / GUI；视频读取失败时会弹出提示。

## 给开发者：数据接口与自行编译

HUD 的数据由下面几个入口推送，都可以在任意线程调用：

| 入口 | 作用 |
|---|---|
| `HudInfo.fps` / `HudInfo.ping` / `HudInfo.user` | 帧率（原生层自动提供）、延迟、用户名 |
| `TargetFeed.push(TargetInfo)` | 目标信息 HUD |
| `PotionFeed.push(List<PotionInfo>)` | 药水效果 HUD |
| `SpeedFeed.pushPosition(x, y, z)` / `SpeedFeed.pushSpeed(bps)` | 速度计；`pushPosition` 同时会更新坐标 HUD |
| `PosFeed.push(x, y, z, yaw)` | 坐标 HUD 与雷达朝向（yaw 为 MC 约定：0=南，90=西，180=北，270=东） |
| `BlocksFeed.push(n)` / `BlocksFeed.clear()` | 方块计数 HUD 与灵动岛的方块进度；停止推送 1.5 秒后自动淡出 |
| `RadarFeed.push(List<RadarTarget(dx, dz, friend)>)` | 雷达；dx、dz 是目标相对自己的世界坐标偏移（格） |
| `HudNotify.push(title, message, kind)` | 通用通知，开关提示卡片和灵动岛都会显示 |
| `ModuleRepo.backend` | 模块真实逻辑接口：实现 `ModuleBackend` 后赋值，即可收到模块开关和设置变化 |

**自行编译**

```
./gradlew assembleRelease
```

- 需要 JDK 17、Android SDK 34、NDK 27.2（原生层用 CMake 3.22.1，只编译 arm64-v8a）；
- 原生层依赖 ByteDance ShadowHook（通过 Gradle / prefab 引入）；
- 原生模糊钩子在 `app/src/main/cpp/rlinhook.cpp`：钩住 `eglSwapBuffers`，在每帧上屏前做模糊和玻璃合成；
- UI 代码在 `app/src/main/java/com/nemoclient/app`，注入宿主与桌面入口在 `app/src/main/java/com/rlin/inject`。
